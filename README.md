# 🛍️ متجر الملابس المتكامل مع لوحة تحكم صاحب المحل (E-Commerce Store & Admin Panel)

موقع ويب متكامل لمحل ملابس شبابي ورجالي، مصمم بأحدث التقنيات ليعمل بسلاسة فائقة على الموبايل واللابتوب مع مزامنة لحظية وحفظ دائم للبيانات.

---

## 🌟 المميزات الرئيسية

### 1. ⚙️ لوحة تحكم خاصة بصاحب المحل فقط (`/admin`):
- **حماية كاملة بكلمة مرور**: لا يمكن لأي زائر الدخول لها إلا بإدخال رمز المرور (الافتراضي: `admin123` ويمكنك تغييره بسهولة من الإعدادات).
- **تغيير اسم المحل واللوجو**: إمكانية رفع صورة اللوجو مباشرة من الموبايل أو الكمبيوتر، وتغيير اسم المحل والشعار بالعربي والإنجليزي.
- **إضافة منتجات جديدة بالصور**: رفع صور المنتجات من كاميرا/معرض الموبايل أو الكمبيوتر مع تحديد السعر، الخصم، القسم، والمقاسات (S, M, L, XL, XXL, إلخ).
- **حذف وتعديل المنتجات**: إمكانية حذف أي منتج فوراً بضغطة زر أو تعديل سعره ومواصفاته.
- **متابعة طلبات الزبائن لحظياً**: معرفة اسم العميل، رقم هاتفه، عنوانه بالتفصيل، المنتجات المطلوبة بمقاساتها، والإجمالي.
- **زر واتساب واتصال مباشر**: للتواصل مع العميل لتأكيد الأوردر بضغطة واحدة.
- **تسليم الأوردر وإزالته فوراً**: عند الضغط على زر "تسليم الأوردر"، يختفي الطلب فوراً من القائمة كما طلبت!

---

### 2. 📱 صفحة الزبون والزائر (`/`):
- **تصميم عصري متجاوب 100%**: يعمل بنفس الكفاءة والشياكة على شاشات الهواتف المحمولة واللابتوب.
- **قائمة تصنيفات الملابس**:
  - 🔥 **الكل** (All)
  - 🧥 **هودي** (Hoodies)
  - 👖 **بناطيل** (Pants)
  - 👔 **قمصان** (Shirts)
  - 👕 **تيشيرتات** (T-Shirts)
  - 🧥 **جواكت** (Jackets)
- **عرض المنتجات بالصور والأسعار**: مع وسوم الخصومات، واختيار المقاسات، والكمية.
- **سلة مشتريات ذكية (Drawer)**: لحساب الإجمالي والكميات بسلاسة.
- **طلب سريع ببيانات العميل**: إدخال الاسم، رقم الموبايل، والعنوان، وإرسال الأوردر فوراً.
- **إرسال الأوردر للواتساب**: زر مباشر يتيح للعميل إرسال نسخة من الفاتورة إلى واتساب صاحب المحل.
- **زر تحويل اللغة (عربي / English)**: زر في أعلى الصفحة يحول الموقع كاملاً من العربية إلى الإنجليزية مع تغيير اتجاه الصفحة (RTL / LTR) فوراً.
- **زر واتساب عائم**: للتواصل السريع مع صاحب المحل في أي وقت.

---

### 3. 🔄 حفظ دائم للبيانات ومزامنة لحظية بين الموبايل واللاب:
- البيانات **ليست مؤقتة** بل محفوظة في قاعدة بيانات دائمة (`data/`).
- أي منتج تضيفه أو تحذفه من الموبايل يظهر في نفس الثانية على اللابتوب بدون الحاجة لعمل تحديث للصفحة بفضل تقنية (Server-Sent Events).
- أي طلب يعمله زبون من موبايله يُصدر رنة تنبيه فورية على لابتوب وموبايل صاحب المحل!

## 🚀 كيفية تشغيل الموقع

### الطريقة الأولى (الأسهل بضغطة واحدة):
- اضغط مرتين على الملف: `start-store.bat`

### الطريقة الثانية (عبر سطر الأوامر):
```bash
npm start
```
